# Offline emoji catalog

`emojis.json` is derived from https://unicode.org/Public/emoji/16.0/emoji-test.txt (Unicode Emoji 16.0, 2024-08-14). It retains all 3,781 fully-qualified emoji sequences, their Unicode English names, and group headings. Minimally-qualified and unqualified duplicates are omitted. See `UNICODE-LICENSE.txt` for the original license. Emoji artwork is supplied by the user's operating-system fonts, not by this data file.
